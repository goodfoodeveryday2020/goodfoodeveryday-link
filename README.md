# 日日好食 Good Food Everyday｜GitHub Pages

這是「日日好食」Linktree 替代頁面的 GitHub Pages 上傳版。

## 最簡單上線方式

1. 登入 GitHub。
2. 建立新的 **Public Repository**。
3. Repository 名稱可以用：`goodfoodeveryday-link`。
4. 建立後進入 Repository。
5. 點 **Add file → Upload files**。
6. 把本資料夾內的 **index.html** 與 **.nojekyll** 上傳到 Repository 的最外層（根目錄）。
7. 按 **Commit changes**。
8. 進入 **Settings → Pages**。
9. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
10. Branch 選 **main**，資料夾選 **/ (root)**，按 Save。
11. 等待 GitHub Pages 部署完成，再點 Visit site。

GitHub Pages 官方文件：
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 網址會是什麼？

如果 Repository 名稱是 `goodfoodeveryday-link`，一般專案網站網址會是：

`https://你的GitHub帳號.github.io/goodfoodeveryday-link/`

如果你想要最漂亮的：

`https://你的GitHub帳號.github.io/`

則 Repository 必須命名為：

`你的GitHub帳號.github.io`

## 之後怎麼改內容？

直接在 GitHub 裡打開 `index.html` → 點鉛筆 Edit → 修改 → Commit changes。

GitHub Pages 會自動重新發布。

## 注意

- `.nojekyll` 請保留在 Repository 根目錄。
- 目前頭像使用原 Linktree 的公開圖片網址。
- Email 按鈕目前是提示按鈕，因為原 Linktree 公開資料沒有提供實際 Email 位址。
- 「日日好食 x 健身博覽會」目前保留文字，但沒有外部連結，因為原 Linktree 公開資料沒有提供該按鈕的外部網址。
